# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. When GitHub Private
Vulnerability Reporting is available for this repository, use the [private
reporting form](https://github.com/SGTA-UTN-FRRe/sgta/security/advisories/new).

If the form is unavailable, contact an organization maintainer through an
existing private channel. Do not share vulnerability details in public issues,
discussions, or pull requests.

### What to include

- Affected component and version.
- Impact assessment.
- Steps to reproduce or a minimal proof of concept.
- Known mitigations, if any.

## Response expectations

Reports are reviewed on a best-effort basis. No response or remediation deadline
is promised.

## Supported versions

Only the latest code on `main` is supported.

## Scope

This policy covers the application source code in this repository. Report
vulnerabilities in third-party dependencies to their respective maintainers.
